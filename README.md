# Cmd+Tab Homebrew Tap

Install [Cmd+Tab](https://www.cmd-tab.com) — the macOS switcher where apps
and individual browser tabs are peers in one recency-ordered list:

```sh
brew install --cask lukeabraham24777/cmdtab/cmdtab
```

Updates ship through the app's built-in Sparkle updater; `brew upgrade`
works too. This cask is regenerated automatically by the app's release
pipeline.
